# Map labels

Every label on the full-area map, generated by `scripts/labels.py` from the OSM features tagged with a Wikidata id (`scripts/fetch_wikidata.py`), and listed here by `scripts/labels_doc.py`. Labels show the Spanish name (the OSM name) with the English one under it where it differs. The required set is fixed in `REQUIRED`; the extended set follows the rules in `labels.py`: places (not boundaries, routes, streets, shops, people, events or organisations) whose Wikidata item has a heritage designation or a Wikipedia article, shown up to a distance that depends on how many Wikipedia editions the item has. To drop a label, add its Wikidata id to `EXTENDED_EXCLUDE` in `scripts/labels.py` (and log it in `DECISIONS.md`).
