# Warsaw reference documents

Research notes and visual references from [warsaw-vibe-voxel](https://github.com/stared/warsaw-vibe-voxel) by Piotr Migdał (MIT), imported with the snapshot this project started from. They describe Warsaw, not Madrid, and are kept as examples of how landmarks were researched and curated there; the Madrid project's own documents are `PLAN.md`, `NOTES.md`, `DECISIONS.md` and `docs/research.md`.
